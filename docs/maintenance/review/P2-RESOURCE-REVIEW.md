This is a complete resource review, not the random paper sample used to estimate error rates in untouched papers.

Important verified fixes include:

- **Major — units and evaluation scope.** Active factor-based evaluation reports 20–40% fewer trials, not an undefined efficiency gain. Critical Interval MSE's correlation comparison uses 27 simulated checkpoints. FailBench's assembly ceiling is at most 0.60. EBRL's approximately 2.5x result is training time for 60 epochs on LIBERO-Object/GR00T PPO in simulation. [Active evaluation](https://arxiv.org/abs/2607.14439), [Critical Interval MSE](https://arxiv.org/abs/2606.29898), [FailBench](https://arxiv.org/abs/2609.03611), [EBRL](https://arxiv.org/abs/2609.27547).
- **Major — data/model and metric distinctions.** RoboTwin 2.0's 367% relative gain uses synthetic data plus ten real demonstrations against the ten-demonstration baseline. AgiBot Colosseo's 30% comparison concerns dataset pretraining, while 32% compares GO-1 with RDT. RoboPhys-3D's 0.9761 human correlation concerns its task-aligned RoboPhyscore, not its separate average of all 50 metrics. [RoboTwin 2.0](https://arxiv.org/abs/2506.18088), [Colosseo](https://arxiv.org/abs/2503.06669), [RoboPhys-3D](https://arxiv.org/abs/2608.28718).
- **Major — COST-HIL manuscript and intervention unit.** The repository does contain `paper/COST_HIL.pdf`; its table reports grasp success 99.9% versus 80.7%, and human-intervened training steps 6% versus 30%. The table's 80% reduction is not a count of interventions per successful attempt. The manuscript was downloaded, its table rendered and inspected, and the description now attributes results to the repository manuscript. Its publication status is not inferred. [COST-HIL repository](https://github.com/alexantaluo0/COST-HIL).
- **Major — release status.** Nautilus's paper promises a future release and its project page labels the main code “Coming Soon.” Removed the unsupported claim that the main framework is already open source. [Nautilus](https://yufengjin.github.io/nautilus/).
- **Major — affiliations and version distinctions.** Corrected BiGym to Dyson Robot Learning Lab; removed unsupported Huawei attribution from *Robots Need More than VLA and World Models*; corrected RoboArena's institution list; distinguished the MIKASA paper's 32 tasks from the repository's later 90-task VLA release. [BiGym](https://arxiv.org/abs/2407.07788), [reward-interface perspective](https://arxiv.org/abs/2606.06556), [RoboArena](https://arxiv.org/abs/2506.18123), [MIKASA](https://github.com/CognitiveAISystems/MIKASA-Robo).
